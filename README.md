# PROXYCHAIN
How proxychains for anonymous pentesting
The screenshots show a DNS leak testing process using a web browser in Kali Linux and the installation of ProxyChains through the terminal. The purpose of these activities is to examine network privacy and prepare a tool for routing network connections through a proxy.
Objectives
To check the public IP address and its apparent geographical location.
To prepare a DNS leak testing environment.
To install ProxyChains in Kali Linux.
To understand how proxy routing can help improve network privacy.
Observations:
The website displays the public IP address 185.220.101.9.
The displayed location is Brandenburg an der Havel, Germany.
Two testing options are available: Standard Test and Extended Test.The page can be used to investigate which DNS resolvers handle DNS queries.Screenshot Analysis
ProxyChains is a utility that can route supported applications' network connections through configured proxies. It can be used with tools such as command-line clients and web browsers, depending on their compatibility and configuration.
